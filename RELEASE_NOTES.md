## Ytdlp-G 1.2.0

A compact Windows 10/11 x64 app for downloading videos, audio, and playlists. Paste a link, choose an available quality, then save regular files or one ZIP.

Choose **Audio only → Quality → MP3 · High quality** to download the best available audio and convert it to MP3 at 320 kbps. MP3 sources are preserved without another lossy conversion. The menus remain readable with a dark Windows system palette.

The installer and portable ZIP include Python, Qt, yt-dlp, FFmpeg/FFprobe, and QuickJS-ng. No Python installation is needed. The binaries are unsigned, so Windows SmartScreen may show a warning.

This release is published only after the Windows build, automated tests, and packaged, portable, and installed application smoke checks pass. Bundled components retain their own licenses; see `THIRD_PARTY_NOTICES.md` and the `licenses` folder in each package.
